## 📋 Программа обучения

### Модуль 1: Знакомство со средой программирования
- Введение в Python, команда `print`, переменные
- Строки, числа, типы данных `int`/`str`/`float`
- Ввод данных через `input`, арифметические операции
- Условные операторы `if`/`elif`/`else`, логические выражения
- Циклы `while`, `for`, функция `range`
- Библиотеки `turtle`, `random`, `sleep`

**Результат:** первая программа на Python

### Модуль 2: Логика, циклы и списки
- Итерация, `break`, `continue`, вложенные циклы
- Обработка исключений `try`/`except`
- Списки: создание, изменение, сортировка
- Индексация и работа с элементами

**Результат:** уверенная работа с циклами и списками

### Модуль 3: Функции и разработка игры
- Функции, аргументы, возвращаемые значения `return`
- Работа с файлами: чтение, запись, контекстный менеджер `with`/`as`
- Библиотека **Pygame**: примитивы, анимация, взаимодействие объектов

**Результат:** собственная 2D-игра

### Модуль 4: Telegram-бот и финальный проект
- Библиотека `telegrambotapi`
- Ветки диалогов, inline-кнопки, обычные кнопки
- Работа со списками и файлами в боте
- Проектирование и презентация собственного проекта

**Результат:** полноценный Telegram-бот

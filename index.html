Программа обучения Python

4 модуля — от первой строки кода до собственного проекта

Модуль 1
Знакомство со средой программирования
  • Введение в Python
  • Подготовка среды программирования
  • Команда print
  • Строки и числа
  • Переменные и базовые структуры данных
  • Базовые правила переменных
  • Кавычки, комментарии, табуляция
  • Библиотека turtle
  • Ввод строк, чисел, обработка
  • Команда input
  • Строковый и числовой ввод int/str/float
  • Арифметические операции
  • Условные выражения
  • Булевые значения
  • Логика условного оператора if
  • Логические выражения и практика
  • if / elif / else
  • Операторы сравнения and / or
  • Отступы и анализ ошибок
  • Цикл while
  • Методы string lower(), upper()
  • Библиотеки random / sleep
  • Цикл for и функция range
Результат: ученики научатся писать код в консоле, использовать встроенные инструменты Python для получения информации от пользователя, применять содержательные имена переменных, исправлять синтаксические ошибки, писать условия и логические цепочки — и создадут свою первую программу.
Модуль 2
Логика, циклы и списки
  • Цикл while, итерация
  • Обработка ошибок try / except
  • Ключевое слово break и continue
  • Вложенные циклы
  • Знакомство со списками
  • Изменение, добавление и удаление элементов
  • Упорядочение и длина списка
  • Ошибки индексирования
Результат: ученики начнут работать с циклами и управлять продолжительностью программ, установят новые библиотеки, научатся эффективно работать со списками в циклах и использовать отступы для определения структуры кода.
Модуль 3
Функции и разработка игры
  • Знакомство с функцией
  • Передача аргументов и вызов функции
  • Возвращаемое значение return
  • Создание программы-помощника
  • Знакомство с файлами
  • Чтение из файла, запись в файл
  • Сохранение данных в файле
  • Менеджер контекста with / as
  • Библиотека pygame
  • Геометрические примитивы и анимация
  • Управление элементами
  • Загрузка изображений в игру
  • Взаимодействие элементов в игре
  • Клонирование элементов в игре
Результат: ученики научатся писать функции и передавать аргументы, узнают, как работает вызов функции и как работать с файлами с помощью кода. Все знания применят на практике — создадут свою первую 2D-игру.
Модуль 4
Telegram bot и работа над своим проектом
  • Библиотека telegrambotapi
  • Условия в чат-боте
  • Функции и возврат функций в чат-боте
  • Ветки чат-бота
  • Inline URL кнопки чат-бота
  • Обычные кнопки чат-бота
  • Работа списков в чат-боте
  • Работа с файлами в чат-боте
  • Библиотеки для чат-бота
  • Проектирование и реализация проекта
  • Финальная презентация проекта родителям
Результат: ученики изучат технологию создания чат-бота на Python, познакомятся с архитектурой построения диалогов с пользователями, научатся создавать кнопки и сделают несколько полноценных ботов в Telegram.
